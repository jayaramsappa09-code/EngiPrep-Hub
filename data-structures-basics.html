1. Taxonomy of Data Structures and Complexity Limits

A **Data Structure** is a specialized format for organizing, processing, retrieving, and storing data in computer storage devices efficiently. Choosing the correct structure is crucial for writing clean, high-performance programs.

Linear vs. Non-Linear Structures

In **Linear Data Structures**, element elements are sequential, with each item having a unique predecessor and successor (e.g., Arrays, Linked Lists, Stacks, Queues). In **Non-Linear Data Structures**, elements form hierarchical or interconnected patterns (e.g., Graphs, Trees, Heaps).

Static vs. Dynamic Classification

**Static structures** have fixed memory allocations determined at compile time (e.g., standard Arrays). **Dynamic structures** can grow or shrink in size during program execution using pointer operations (e.g., Linked Lists, Trees).

Mathematical Concept

Asymptotic Complexity Notation

We analyze algorithm efficiency mathematically by looking at how resource usage scales with input size ($n$). The three standard asymptotic notations are:

  • Big-O Notation ($\mathcal{O}$): Represents the upper bound on runtime, describing the worst-case scenario. Formally, $f(n) = \mathcal{O}(g(n))$ if there exist positive constants $c$ and $n_0$ such that $0 \leq f(n) \leq c \cdot g(n)$ for all $n \geq n_0$.
  • Big-Omega Notation ($\Omega$): Represents the lower bound on runtime, describing the best-case scenario. Formally, $f(n) = \Omega(g(n))$ if there exist positive constants $c$ and $n_0$ such that $0 \leq c \cdot g(n) \leq f(n)$ for all $n \geq n_0$.
  • Big-Theta Notation ($\Theta$): Represents the tight bound on runtime, describing average-case behavior. Formally, $f(n) = \Theta(g(n))$ if there exist positive constants $c_1, c_2$ and $n_0$ such that $c_1 \cdot g(n) \leq f(n) \leq c_2 \cdot g(n)$ for all $n \geq n_0$.

2. Multi-Dimensional Array Memory Mapping

Computer memory is linear and single-dimensional. To store multi-dimensional arrays, we must map multi-dimensional coordinates to linear memory addresses using formulas.

Row-Major and Column-Major Formulas

Consider a 2D array defined as $A[R][C]$ with base address $B$ and element size (width) $W$. The coordinate mapping for find the memory address of element $A[i][j]$ is:

Row-Major: Address(A[i][j]) = B + W × ( i × C + j )
Column-Major: Address(A[i][j]) = B + W × ( j × R + i )

Important Exam Note: When array indexing starts at custom lower bounds ($L_r$ for rows, $L_c$ for columns) instead of 0, the formulas are:

Row-Major: Address(A[i][j]) = B + W × [ (i - L_r) × C + (j - L_c) ]
Column-Major: Address(A[i][j]) = B + W × [ (j - L_c) × R + (i - L_r) ]

3. Pointer Redirection & Stack/Queue Execution States

Dynamic memory allocation allows us to create flexible structures using self-referential structures (structures containing pointers to the same structure type).

A. Singly Linked List Node Insertion Mechanics

Inserting a node $N$ into a Singly Linked List after target node $T$ requires a specific sequence of pointer assignments to avoid breaking list connectivity or leaking memory:

1. N->next = T->next; // Connect new node to downstream nodes
2. T->next = N; // Redirect target node to the new node

B. Circular Queue Rollover Equations

Standard linear queues suffer from memory fragmentation; once the rear index reaches max capacity, we cannot insert more elements even if space is available at the front. **Circular Queues** solve this by using modulo arithmetic to wrap indexes back to the beginning of the array.

Enqueue: rear = (rear + 1) % MAX_SIZE;
Dequeue: front = (front + 1) % MAX_SIZE;
Check Full Condition: (rear + 1) % MAX_SIZE == front;

4. Trees, BST Deletion Rules, and Partition Algorithms

A. Binary Search Tree (BST) Node Deletion Edge Cases

Deleting a node from a BST is simple for leaf nodes or nodes with only one child. If the node has two children, we must find a suitable successor to preserve the BST property:

  • Identify **Inorder Successor** (the smallest element of the right subtree) OR **Inorder Predecessor** (the largest element of the left subtree).
  • Copy the value of the successor into the target node.
  • Recursively delete the successor node from its respective subtree.

B. Hash Collision Resolution Mathematics

When a hash function maps two distinct keys to the same index, a **collision** occurs. The two standard collision resolution strategies are:

  • Separate Chaining (Open Hashing): Each bucket in the hash table points to a linked list of records that map to the same hash value. This approach handles high insert/delete loads gracefully.
  • Open Addressing (Closed Hashing): All elements are stored directly in the hash table array. If a collision occurs, we probe other indices systematically until an empty slot is found.
    Linear Probing: h(k, i) = ( h'(k) + i ) % m
    Quadratic Probing: h(k, i) = ( h'(k) + c1 × i + c2 × i^2 ) % m
    Double Hashing: h(k, i) = ( h1(k) + i × h2(k) ) % m

Singly Linked List (SLL) Basic Operations

A complete C program implementing insertion, traversal, and memory cleanup in an SLL.

#include <stdio.h> #include <stdlib.h> struct Node { int data; struct Node* next; }; void printList(struct Node* n) { while (n != NULL) { printf("%d -> ", n->data); n = n->next; } printf("NULL\n"); } void insertAtHead(struct Node** head_ref, int new_data) { struct Node* new_node = (struct Node*)malloc(sizeof(struct Node)); if (new_node == NULL) { printf("Out of system memory bounds!\n"); return; } new_node->data = new_data; new_node->next = (*head_ref); (*head_ref) = new_node; } int main() { struct Node* head = NULL; insertAtHead(&head, 10); insertAtHead(&head, 20); insertAtHead(&head, 30); printf("Current Singly Linked List: \n"); printList(head); // Memory cleanup struct Node* temp; while (head != NULL) { temp = head; head = head->next; free(temp); } return 0; }

Binary Search (Iterative Implementation)

An iterative binary search algorithm implementing standard $\mathcal{O}(\log n)$ complexity boundaries.

#include <stdio.h> int binarySearch(int arr[], int size, int target) { int low = 0, high = size - 1; while (low <= high) { int mid = low + (high - low) / 2; // Prevents overflow errors if (arr[mid] == target) { return mid; } if (arr[mid] < target) { low = mid + 1; } else { high = mid - 1; } } return -1; // Target not found } int main() { int sortedArray[] = {2, 5, 8, 12, 16, 23, 38, 56, 72}; int n = sizeof(sortedArray) / sizeof(sortedArray[0]); int target = 23; int result = binarySearch(sortedArray, n, target); if (result != -1) { printf("Element found at index location: %d\n", result); } else { printf("Element is not present in array structures.\n"); } return 0; }
