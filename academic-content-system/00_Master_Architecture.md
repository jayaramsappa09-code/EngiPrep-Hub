# EngiPrepHub Academic Content Generation System
## Master Architecture

This system is designed to generate top 0.1% quality educational content for Engineering Students (JNTUK R23).
It replaces generic AI prompts with a multi-layered, role-based, quality-assured generation pipeline.

### The 4-Layer System
1. **Layer 1: Master Rules** - Global standards on tone, 13-section structure, visual assets, and SEO.
2. **Layer 2: Subject Blueprints** - Domain-specific pedagogy (e.g., Engineering Graphics CAD workflows vs. C Programming memory dry runs).
3. **Layer 3: Topic Generator** - Topic-specific prompt builder enforcing focused generation.
4. **Layer 4: Faculty Team AI Review Checklist** - Mandatory quality gate requiring 10/10 audit verification before final rendering.

### The 6-Persona Faculty Review Matrix
Content is never generated in a single pass. It must pass through simulated faculty audits:
- **Professor:** Concept accuracy, scientific facts, & zero-skipped mathematical derivation steps.
- **Department HOD:** JNTUK R23 syllabus alignment, course outcomes, & mark weightage tags.
- **Paper Setter:** 5-year PYQ solutions, problem difficulty progression, & exam trap alerts.
- **Topper:** Memory tricks, mnemonics, & 'Exam Tomorrow' rapid cramming summaries.
- **Instructional Designer:** Visual break rhythm, inline SVG vector diagrams, & CAD command matrices.
- **Technical Writer:** Elimination of AI conversational fluff, active voice, & Schema.org microdata.
