📌 Mid-Term Exam Composition

Under the latest R23 academic regulations, each semester includes two mid-term examinations. Each midterm is structured as follows:

  • Theoretical Descriptive Portion (15 Marks): Evaluated manually by college examiners on structural paper answer scripts.
  • Online Objective Quiz Portion (10 Marks): Held in computer labs. Represents 10 MCQs spanning your entire units syllabus.
  • Assignment Portfolio / Quiz Activities (5 Marks): Based on continuous classroom quiz participation and project file reports.

Problem Solving with C

Pointers and Size Calculation

A highly frequent university question concerns calculating memory sizes. Remember that pointer size is determined strictly by the underlying computer architecture, not the data type it references! On a standard 64-bit platform, both char* and double* allocate exactly 8 bytes of storage space.

Engineering Physics

Wave Interference in Air Films

Exams frequently query the phase-shift during reflection. When light wave packets hit a denser boundary (such as air-to-glass in Newton's rings), they undergo a phase change of π (or paths match equal to λ/2). This Stokes relationship shifts interference nodes, ensuring a dark center fringe.

Mathematics-I

Matrix Rank & Enchanced Solutions

For non-homogeneous linear systems representable as AX = B, a solution exists if and only if the rank of the coefficient matrix A equals the rank of the augmented matrix [A|B]. If rank(A) = rank(A|B) = number of system variables, the system possesses a unique, singular solution path!

Frequently Academic Questions (FAQs)

Q.1 Does JNTUK penalize incorrect objective answers with negative marks?

No. JNTUK continuous internal quiz assessments do not apply any negative mark algorithms. You are highly encouraged to answer every single question. Always eliminate obviously incorrect answers first (such as negative capacities or non-integer pointer sizes) to maximize your chances on guess work.
